# 功能清单验收对照

依据用户提供的《feature-list.md》（年轻用户优化版）。本表区分“管理配置已实现”和“运行链路已经执行”。没有真实设备、模型凭证、音色克隆服务或唤醒词训练产物时，不将这些项标记为端到端完成。

状态含义：**已实现**表示本地管理/API 行为可运行；**已接入、待实测**表示代码连接至原有服务但仍需真实服务/设备验证；**配置已实现**表示可保存与维护，但没有完整执行引擎；**待外部接入**表示还需厂商工具、服务商或终端实现。

| OTA 地址配置 | 配置已实现；原终端高级配网/编译预置能力保留。管理库字段不会自行重写旧设备 NVS。 |

## 验证范围

后台回归 **60 项通过**，涵盖管理 API 持久化、校验、鉴权、配置回滚、调度、模型主备与用户/访客隔离等。Chrome 浏览器通过 23 个流程，覆盖 23 页签与桌面/移动尺寸；未发现页面级横向溢出和 JavaScript 异常。原设备 host 测试有 12 项 Windows/工具链环境错误及 25 项跳过，未完成 ESP-IDF 编译。真实 OTA、声纹准确率、麦克风/扬声器回环、相机和外部服务计费调用需要对应环境。不要将本表中的“配置已实现”认作清单功能全部上线。
