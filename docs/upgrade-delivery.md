交付日期：2026-11-06。

## 直接启动

解压项目，在根目录执行：

```bash
python backend/console/server.py --host 127.0.0.1 --port 8004
```

需要 Python 3.10+。Windows 可运行 `start-console.cmd`。浏览器打开 `http://127.0.0.1:8004`。已包含生产构建文件，运行管理后台不需要安装 Node 或前端依赖。

要修改前端，进入 `backend/console/frontend` 执行 `npm ci` 和 `npm run build`。
