以下为**面向年轻用户（约18–35岁）优化版**。优化原则：强调**效率、个性化、娱乐陪伴、隐私可控、低打扰、快速交互**；删除儿童/适老化、家庭多角色照护、用药/久坐等强家庭场景功能；保留核心 OTA、模型网关、语音音色、声纹记忆、视觉、监控和交互配置。标签说明：**【后台】**管理后台/服务端配置管理；**【终端】**设备端执行/采集/播报；**【两端配合】**后台配置下发、终端执行上报。

---

**小智AI后台完整功能清单（年轻用户优化版）**

## 一、OTA 升级管理

**固件版本管理【后台】**
后台上传、登记、标记固件版本，记录版本号、适用芯片型号、变更说明和发布日期。

**OTA 地址配置【两端配合】**
后台为设备指定 OTA 查询地址并维护管理视图；终端支持配网高级选项中手动填写，或固件编译时预置默认地址。

**设备升级状态查看【后台查看 / 终端上报】**
后台按设备查看当前固件版本、最近一次 OTA 检查时间、升级结果；终端上报版本和升级结果。

**分批与时间窗推送【后台】**
后台按设备分组、用户群或指定比例分批推送升级，可限定允许升级的时间段，默认避开夜间高频使用时段。

**强制升级开关【后台配置 / 终端执行】**
后台对关键更新设置强制升级标志；终端上线后未完成升级不进入正常服务。年轻用户场景下建议仅用于安全修复。

**升级前环境校验【两端配合】**
终端检查网络稳定性和供电状态并上报；后台根据上报结果决定是否暂缓下发。

**外部定时 OTA 检查调度【后台调度 / 终端响应】**
后台提供服务端外部调度配置，如 systemd timer 或后台定时任务，周期性触发“检查新版本”；终端响应检查请求。

**版本回滚【两端配合】**
后台记录设备上一可用固件版本并下发回滚指令；终端执行回退，后台记录结果。

## 二、唤醒词与资源包（个性化资源层）

**预设唤醒词选择【后台配置 / 终端生效】**
后台从芯片支持的唤醒词列表中选择并下发；终端使用对应 WakeNet 模型。ESP32-S3 支持较全列表，C3/C6 仅支持 WakeNet9s 子集。

**自定义唤醒词输入【后台配置 / 终端生效】**
仅 ESP32-S3 开放，后台支持中文拼音和英文自定义词，可配置阈值与超时时间；后台按芯片型号拦截，C3/C6 不展示入口。终端使用生成的资源包生效。

**唤醒词资源包生成与下发【两端配合】**
后台将唤醒词模型与字体、表情等资源打包为 `assets.bin`，通过 OTA 或独立下载通道下发；终端写入 `assets` 分区。

**资源包版本管理与回滚【两端配合】**
后台记录每次生成的资源包版本，保留上一可用包；终端写入失败时由后台触发回滚。

**自定义表情包管理【后台管理 / 终端展示】**
后台创建表情包项目，上传 PNG/GIF，校验尺寸、格式和 neutral 默认图，为 happy、sad、thinking 等情绪标签指定表情并预览映射；终端按映射展示。适合年轻人做个性化表情和角色形象。

**芯片与 Flash 容量提示【后台】**
后台根据设备 Flash 容量（4MB / 16MB）对 MultiNet 自定义唤醒词给出提示或禁用选项。

## 三、大模型接入与网关

**多提供方配置【后台/服务端】**
后台支持 OpenAI、DeepSeek、通义千问、智谱、Claude、Gemini、豆包、Kimi，以及任意 OpenAI 兼容接口，配置 `base_url`、`api_key`、`model_name`。

**连通性测试【后台/服务端】**
后台保存配置前对接口做轻量调用验证，避免错误配置进入线上对话。

**按设备绑定默认模型【后台/服务端】**
后台为每台设备指定默认大模型通道并记录绑定关系；终端对话请求由服务端按绑定关系路由。

**故障降级【后台/服务端】**
主模型超时或报错时由服务端自动切换到备用模型，后台记录降级日志；终端无感。

## 四、语音与音色

**音色选择【后台/服务端配置 / 终端播报】**
后台从 TTS 服务商音色列表中选择设备播报声音；音色由服务端 TTS 配置决定，终端不写死，后台修改后无需重新烧录即可生效。

**音色克隆管理【后台/服务端】**
后台接入音色克隆服务，创建、命名、删除自定义音色，并分配给指定智能体或设备；终端只负责播报。保留年轻人个性化音色需求。

**音色缓存与预热【后台/服务端】**
服务端对高频克隆音色做特征缓存，启动时预热常用音色，减少 TTS 冷启动延迟；终端无配置动作。

**预设音色风格标签【后台】**
后台为音色配置温柔、活泼、沉稳、清冷、元气、故事感、客服等风格标签，支持筛选和推荐。删除“儿童/适老”标签。

**音色试听与对比【后台】**
后台提供在线试听、多音色对比和示例话术试听，保存配置前验证音色与角色人设是否匹配。

**按角色、时间段和用户身份切换音色【后台配置 / 服务端生效 / 终端播报】**
后台为不同智能体角色、时间段（白天/夜间）、用户身份配置不同音色并记录规则；服务端按规则选择 TTS 音色，终端播报。

**语速音量默认模板【后台配置 / 服务端或终端生效】**
后台提供默认、夜间低音量、快速问答、沉浸故事等语速音量模板，支持按设备或用户群覆盖。删除儿童/老人模板。

## 五、声纹识别与多用户记忆

**声纹注册与管理【两端配合】**
终端采集声纹并上报；后台维护声纹 ID 与用户身份映射。声纹识别与 ASR 并行，识别结果传递给 LLM。

**多用户独立记忆【后台/服务端】**
后台和服务端为不同注册用户维护独立对话记忆和个性化回应，防止跨用户上下文混淆；终端不保存跨用户记忆。适合合租、情侣、朋友共用设备。

**长期记忆管理【后台/服务端】**
后台接入 mem0ai、PowerMem 等长期记忆系统，支持记忆总结、记忆图谱和跨会话记忆。

**对话记录查看【后台】**
后台按设备、用户、时间查看和检索历史对话记录。

**共享/临时访客模式【后台配置 / 服务端与终端执行】**
后台配置临时访客或共享模式；服务端不读取个人长期记忆、不暴露他人对话记录，终端使用受限话术和默认音色，并记录独立日志。保留简化版，删除家庭多角色称呼。

**记忆可见范围【后台/服务端】**
后台按用户和设备配置“仅本人可见”“共享设备可见”等记忆可见范围，服务端执行隔离。

**用户说“忘记我”时的删除流程【两端配合】**
终端接收用户语音“忘记我/删除我的记忆”并上报；后台生成待确认任务，执行删除范围、记录结果和审计日志，保留合规删除凭证。

## 六、视觉理解

**浏览器摄像头作为“眼睛”【两端配合】**
后台开启浏览器摄像头并提供远程摄像头能力；终端通过 MCP 调用远程摄像头获取图片，服务端视觉大模型解析后返回终端。适合桌面陪伴、穿搭/环境识别等年轻场景。

**视觉模型配置【后台/服务端】**
后台接入 Qwen-VL、GLM 等视觉模型，管理 API 配置和可用性；终端不直接配置模型。

**设备端摄像头支持【两端配合】**
后台管理摄像头分辨率、拍照触发和视觉问答配置；终端摄像头执行拍照并上传，服务端解析后返回。

## 七、监控与运维看板

**Token 消耗看板【后台】**
后台按设备、模型、时间维度统计 Token 用量，识别高消耗通道。

**时延看板【后台】**
后台分段展示 ASR 耗时、LLM 首 token 耗时、LLM 成句耗时、TTS 首帧耗时和端到端总时延。参考数据：ASR 500–800ms，LLM 首 token 300–600ms，LLM 成句 800–1500ms，TTS 首帧 200–400ms，端到端约 1000–1300ms（区间 800–1800ms）。

**设备活跃度看板【后台】**
后台展示在线设备数、日活、对话轮次等运营指标；数据由终端和服务端上报汇总。

**设备接入自检【两端配合】**
后台对单台设备发起连接测试、ASR/TTS 回环测试和 MCP 工具可用性检查；终端执行测试并回传结果。

**交互质量看板【后台】**
后台统计唤醒成功率、误唤醒率、打断成功率、澄清率、兜底率、主动提醒退订率、差评率和用户满意度，支持按设备、角色、用户群、模型和时间段下钻；数据来自终端上报和服务端日志。

## 八、人机交互与对话体验管理

**交互人格与角色预设【后台配置 / 服务端与终端生效】**
后台内置角色模板库，面向年轻人提供效率助手、学习搭子、情绪树洞、故事/角色扮演、游戏陪玩、智能家居助手、客服问答等模板。每个模板预设人设描述、语气风格、称呼方式、回复长度、禁用话题、默认音色和开场白，可按设备或用户群绑定。删除儿童陪伴、老人关怀模板。

**预设开场白与唤醒应答【后台配置 / 终端播报】**
后台为不同场景预设唤醒后的第一句话，如“我在”“怎么了”“需要我做什么”。支持按时间段、设备类型、用户身份切换；终端在唤醒后播报对应内容。

**对话风格预设【后台配置 / 服务端生成 / 终端播报】**
后台提供简洁、自然、亲切、活泼、专业、耐心、清冷、梗文化等风格模板。可配置单次回复最大句数、口语化程度、是否主动追问、是否使用表情符号/语气词、是否允许网络流行语；服务端按模板生成，终端播报。删除儿童化、适老化风格。

**追问与澄清策略预设【后台配置 / 服务端执行 / 终端播报】**
后台预设“没听清”“信息不足”“存在歧义”“超出能力范围”时的追问话术；服务端按策略生成追问，终端播报。包括引导重复、只追问一个关键问题、先确认主意图、给出替代建议。

**兜底话术与能力边界预设【后台配置 / 服务端执行 / 终端播报】**
后台为 ASR 失败、LLM 超时、TTS 失败、工具调用失败、内容被拦截、设备离线分别预设兜底话术，提供普通版和简洁版，并配置“转备用模型/建议稍后再试”等动作；服务端选择话术，终端播报。删除儿童版、老人版、客服版中的重照护话术。

**多轮对话与上下文策略预设【后台配置 / 服务端执行 / 终端指令】**
后台预设上下文保留轮数、话题切换判定、会话超时、跨会话记忆开关、敏感信息不记忆规则；服务端维护上下文，终端支持“继续刚才的话题”“重新开始”“忘记这段对话”等指令，后台提供会话恢复和上下文清理入口。

**打断与轮次控制预设【两端配合】**
后台配置打断后行为：立即停止播报、短停顿后继续、降低音量继续、直接进入倾听；配置“只响应唤醒词”“免唤醒连续对话”“单轮问答”“多轮陪伴”等模式，以及 VAD 灵敏度、静音等待、最大录音时长。终端执行打断、VAD 和录音控制。适合年轻人快节奏交互。

**情绪识别与回应预设【两端配合】**
终端/服务端识别 happy、sad、angry、anxious、neutral、thinking 等情绪；后台配置情绪对应回应策略、表情包、音色和回复模板，并支持映射预览。服务端生成回应，终端播报和展示表情。

**主动交互与提醒预设【后台配置调度 / 终端播报】**
后台预设日程提醒、天气变化、设备异常、长时间未互动关怀等主动服务模板，配置触发条件、允许时间段、频率上限、免打扰时段和退订入口；服务端调度，终端播报。删除用药提醒、久坐提醒、儿童学习提醒、节日问候等强家庭照护项。

**快捷指令与常用意图预设【后台配置 / 服务端识别 / 终端执行】**
后台内置定闹钟、查天气、放音乐、讲故事、问时间、记事情、打电话给家人、开关功能、查询设备状态等指令模板；服务端识别意图，终端执行或播报。后台查看未识别指令和高频失败意图，支持补充同义词、示例句和回复模板。

**内容安全与分级预设【后台配置 / 服务端拦截 / 终端播报】**
后台预设敏感话题、医疗建议、金融建议、隐私索取、暴力色情等拦截规则，按用户群配置拒答话术、温和引导和人工复核入口；服务端执行拦截，终端播报边界提示。保留合规底线，简化未成年人分级配置。

**用户反馈与对话质检预设【两端配合】**
终端支持用户语音说“这个回答不好”并标记最近一轮对话；后台预设反馈标签：答非所问、太啰嗦、太冷淡、听不清、打断失败、音色不喜欢、内容不合适、唤醒不灵。后台按设备、模型、角色、场景聚合差评并生成优化任务。

**交互评测用例预设【后台】**
后台内置回归测试集模板，覆盖唤醒、打断、多轮、方言/口音、噪声环境、敏感内容、工具调用失败、模型超时等场景；修改角色、提示词、音色、模型或安全规则后一键跑用例并对比通过率、时延和差评率。终端可作为被测对象参与。删除儿童话术、老人慢语速专项用例。

**A/B 与灰度交互策略【后台】**
后台对开场白、回复风格、追问策略、音色、主动提醒频率做 A/B 测试和灰度发布，按设备分组、用户群、地区、时间段配置实验比例，观察对话完成率、打断率、重复唤醒率、差评率和 Token 成本后全量；终端和服务端按灰度规则生效。

**交互配置模板与克隆【后台】**
后台将角色、话术、音色、情绪映射、安全规则、主动服务、快捷指令保存为“交互配置模板”，复制到新设备或新用户群；模板记录版本、变更说明、上一可用版本，并支持一键回滚。终端按模板生效。
